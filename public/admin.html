這裡是只有你們看得到的後台：左邊每一顆分頁就是賓客會看到的一塊內容。 改完按下該頁的儲存就生效，賓客重新整理就看得到。
不確定改出來長怎樣時，按右上角的「查看目前網站」—— 那就是賓客現在打開連結會看到的樣子。

從這裡開始

照這個順序做一次，該有的東西就齊了。每一步都可以之後再回來改， 現在填不完也沒關係。

    幾件常被問到的事

    改了東西，賓客什麼時候看得到？

    按下儲存就生效了。賓客那一頁重新整理就是新的內容，不用等我們。

    哪些東西後台改不動？

    婚禮日期、網址、要開哪幾個功能，這幾件會牽動倒數計時與分享連結， 要改請直接告訴我們。日期以外的「開始時間、地點、交通」你們自己改得動。

    側欄有幾顆掛著鎖頭，那是什麼？

    那是還沒開通的功能。點得進去看它長什麼樣子，想開通再告訴我們，現有的資料都不會動。

    照片可以自己上傳嗎？

    交通圖、桌次圖、婚禮小卡、故事牆、Dress Code 參考圖都可以自己上傳。 大廳的封面照與照片集放在這場婚禮的素材資料夾裡，要換的話把檔案給我們。
